# Botbox

Open-source, self-hostable persistent AI agents. Each bot lives in its own desktop container on a Linux server, acts via terminal and Chrome, and sends traffic out through the user's home IP.

This repo currently holds the implementation plan. Follow it as written:

- [planning/botbox-plan.md](planning/botbox-plan.md) — the plan (authoritative)
- [planning/botbox-verified-facts.md](planning/botbox-verified-facts.md) — verified CLI/API facts the plan depends on
